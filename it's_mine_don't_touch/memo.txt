gittest (관리대상 폴더)

git init => .git 폴더 생성
		master 브랜치 생성(주 브랜치) or main 브랜치로 하기도 함

1) 새로운 파일 생성 : Untracked files
2) git add newfile 추가 : Staged 영역
   git add . 
3) git commit -m "메세지" : 로컬저장소 저장
    참고) i (insert) / esc => :wq (write quit)
    커밋메세지 필수임

관리하고 있던 기존 파일(commit 이 된 파일) 수정
1) modified 상태
2) git add modifiedfile 추가 : Staged 영역
3) gir commit -m "메세지"

+2,3 같이 실행가능
git commit -a -m "메세지"

저장소 파일과 modified 파일의 비교
git diff

관리하고 있던 기존파일 삭제
1) deleted 상태
2) git add modifiedfile 추가 : Staged 영역
3) gir commit -m "메세지"

커밋 자체 제거

브랜치

git branch

① 브랜치 이름 변경 : git branch -m main
② 브랜치 새로 변경 : git branch 브랜치명
    - 주브랜치 내용을 놔두고 새로운 기능 추가
    - 협업 시 개별 브랜치 생성
③ 브랜치 이동 : git checkout 브랜치명
		     git switch 브랜치명
  
  checkout : 브랜치 이동 + 이동시 브랜치 복사해서 이동하기
